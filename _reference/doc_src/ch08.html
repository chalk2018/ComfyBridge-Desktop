第 08 章手机端（同一套功能，另一种摆法）

一、原则：只是摆法不同，功能一个不少

手机上不砍功能，只换摆放方式。屏幕窄，三栏塞不下，于是：

桌面手机
左栏能力列表常驻收进左侧抽屉，点顶栏最左的 ☰ 拉开
右栏状态与任务常驻收进右侧抽屉，点顶栏的「任务」图标拉开
按钮带文字标签按钮只留图标，文字藏起来（功能不变）
整页滚动整屏固定，只有聊天区内部滚
输入区想多高就多高输入区最高占半屏，超出的部分在里面滚

二、屏幕上的四块

2.1 顶栏：菜单最左，状态居中

位置元素行为
最左☰ 菜单拉开左抽屉（创作台是能力列表，管理台是页面菜单）
其次Logo + ComfyBridge屏幕特别窄（≤480px）时只留 Logo，把位置让给按钮
正中状态灯 + 已连接/未连接 + 空闲/生成中 小胶囊绝对定位在中轴上，左右按钮各占一边，不会把状态挤歪。这里只报状态，不写描述——「ComfyUI 未连接，请先启动」这种整句留给抽屉里那块
右侧任务 / 历史 / 管理台 三个图标任务 = 拉开右抽屉；历史 = 历史页；管理台 = 管理台

桌面用字符图标（🗂 ⚙），手机换成线性图标。同一份代码，靠 CSS 切换，不是两套页面。

2.2 左抽屉：能力 / 管理台菜单

属性值
宽度屏幕宽的 80%，最大 308px
高度占满整个竖屏（100dvh），不是只占内容高度——否则下面会空出一大块，看着像菜单缺了一角
内容顶部标题栏（标题 + 关闭 ×）→ 下面是列表；超出可滚动，滚到底不会带动后面的页面
关闭方式点选任意一项（自动收起）、点关闭键、点右侧遮罩
安全区底部留出手机手势条的高度，最后一项不会被遮住

管理台的抽屉是同一套：五页菜单 + 2 档位表 下面挂的能力子菜单，缩进照旧保留。

2.3 右抽屉：ComfyUI 状态与本会话任务

属性值
位置与宽度从右侧滑出，占屏幕约 1/3（最小 300px，最大 88%）
内容标题栏「ComfyUI 状态与本会话任务」→ ComfyUI 状态块 → 任务清单
全选 / 批量删除改成了图标按钮：全选是勾选图标，批量删除是垃圾桶图标，右上角带一个红色数字角标显示已选条数
关闭方式点关闭键或点遮罩

2.4 输入区：最高半屏，底栏常驻

角色设定图的输入区有五行分段按钮加描述框，桌面上一屏放得下，手机上会直接把聊天区吃掉。所以手机上给输入区设了硬上限：

规则具体行为
整体高度最高 屏幕的一半（50dvh）
滚动位置滚动只发生在中间那块内容区（版式/画法/参考/档位/风格 + 描述框），描述框里也能滚
底栏「上传 / 收起提示词 / 复制 / 发送」永远露在外面，不用滚到底才能点发送
安全区底部留出手势条高度

三、逐条验收（手机上点一遍）

#动作应有的表现
1打开创作台顶栏一横条：最左 ☰，接着 Logo，状态正好在屏幕正中，右侧三个图标
2点 ☰左抽屉从左侧滑出，占满整个竖屏高度，下面没有空白缺口
3点抽屉里任一能力切到该能力，抽屉自动收起
4点抽屉外面抽屉收起
5点顶栏「任务」图标右抽屉从右侧滑出，宽约屏幕 1/3
6看右抽屉的「全选 / 批量删除」都是图标按钮，批量删除带红色数字角标
7进角色设定图输入区不超过屏幕一半，中间那块能滚，底栏「发送」一直看得见
8输一段长描述描述框内部滚动，输入区不会越撑越高
9进管理台菜单同样是左抽屉，点 ☰ 拉开，抽屉占满竖屏
10进管理台「能力与工作流」卡片一行放得下：图标和文案在左，开关和「配置」在右，卡片比以前矮
11进管理台「档位表」档位名不会被挤成竖排字；页头「保存」靠右，「返回列表」在左
12进管理台「设定图模板」「已实测组合」不再是横表格，每一项竖排成一张小卡（左边标签右边值）；「保存」靠右
13进历史两列瀑布式，像相册
14手指点成品图悬浮按钮不用"悬停"就常驻可见（触屏没有 hover）
15在右抽屉里点「批量删除」确认弹窗盖在抽屉上面，不被遮住
16把手机横过来仍然可用，输入区随高度自适应

四、手机上明确不做的事

不做为什么
不单独做一套手机页面一套代码 + 媒体查询就够，两套页面迟早会出现"手机能点、电脑不能点"的差异
不在手机上做参数微调档位表那种十来个数字输入框，在手机上改容易点错。手机上只做「选档位」，改参数回电脑
不在顶栏写长句描述状态只报「已连接 / 未连接 + 空闲 / 生成中」，说明文字放抽屉里
不靠 hover 暴露操作触屏没有悬停，所有操作按钮默认可见
