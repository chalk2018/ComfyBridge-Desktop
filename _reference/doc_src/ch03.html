第 03 章功能规格（以当前画面为准）

本章不写"应该怎样"，只写"现在点开看到什么、点什么会发生什么"。每条描述都能在界面上找到对应的控件；界面上没有的东西，这里也不会出现。截图全部取自当前版本的真实运行界面。

一、创作台：图片生成

1.1 一屏分三栏

打开应用就是创作台。除了顶栏和底部输入区，中间横着分成三栏：左边是能力列表，中间是对话流（任务卡一张接一张），右边是本次会话的任务清单。

区域里面有什么怎么用
顶栏（吸附在顶部）应用图标与名称、ComfyUI 连接状态、🗂 历史、⚙ 管理台状态灯绿色=已连接，红色=未连接。右边两个按钮切到另外两页
左栏 · 能力列表17 个能力，按分组排列点哪个就切到哪个能力的输入区；灰色带「未配置」标记的点了没反应
中栏 · 对话流任务卡，从下往上追加主战场：提交、看进度、看成品、复制图片、重跑。滚动条在这个区域内侧，不在整页最外面
右栏 · 本会话任务上半固定：ComfyUI 状态 + 执行队列 + 全选/批量删除；下半滚动：任务清单滚到任务中间也能看到状态、能点全选和删除；每条任务底部带一行缩略图（找不到原图给占位图标），每条高度一致
底部输入区模式、档位、参考图、描述框、发送内容随能力变化（见 §1.5）

1.2 左栏：17 个能力，2 个能用

能力列表是写死在 config.yaml 里的固定清单，顺序也固定。每个能力右边会带一个状态标记：

状态标记含义点它会发生什么
无标记（正常黑字）已挂上工作流、有档位，可用切换到这个能力的创作界面
未配置（下个版本开放）能力位留着，但还没接 ComfyUI 工作流点了不切页，只提示还没开放

当前版本可用的是 2 个：🖼️ 图片生成、👤 角色设定图。其余 15 个（参考风格生图、线稿图生成、简单手绘创作、场景设定图、道具设定图、4/6/9 宫格故事板、视频生成、参考生成视频、首尾帧生成视频、音乐生成、参考生成音乐、语音生成、声音克隆）都还是「未配置」。

为什么把没配的也列出来：这三个字不是给用户看的，是给"要不要现在去配"这个决定看的。列表在，说明这个能力的位置已经留好了，挂个工作流就能用，不用改代码。

1.3 中栏：一张任务卡从提交到成品

每次点发送就新开一张卡。一张卡就是一个任务，卡里可以挂多个成品（批量出图时）。

卡上的位置显示什么点它会怎样
卡头已完成 · 参考生图 默认 用时 21 秒——状态 · 跑的是哪个子工作流 · 用的是哪一档 · 花了多久不可点，纯信息
成品图图片按原比例完整显示（object-fit:contain，不裁切）点开看大图
成品上的三个悬浮按钮⤢ 看大图 · ⬇ 下载 · ⧉ 复制图片分别是：弹大图窗 / 存到本地 / 把图片二进制写进剪贴板
提示词区完整提示词，最多 5 行，超出在框内滚（有细滚动条）；下面一行是 看完整提示词 + 子工作流 · 档位 · 字数点「看完整提示词」弹窗看全文。图片生成 / 角色设定图 / 未来的视频音频生成都用这一套卡片版式
成品右下角1024×1024 这样的真实尺寸不可点。放在右下角是为了不挡按钮
卡底三个按钮🕒 加入队列生成 · ↻ 再来一张 · ↗ 基于上一条见下表
右上角 ✕删除按钮把这张卡移出本次会话。只从列表里消失，图片文件不动，历史里照样能找到

卡底三个按钮的区别

按钮做什么什么时候用
🕒 加入队列生成用和这张卡完全相同的参数与种子再排一个任务，但排在队尾，不打断正在跑的那张想多要一张一样的，又不想等它插队
↻ 再来一张同档位、同描述，换一个新种子重新生成，新开一张卡构图还行、想再看看别的随机结果
↗ 基于上一条把这条的描述（完整提示词，含换行）、档位、参考图和风格（含自定义风格及填写内容）填回输入区，不动队列想改几个字再生成，不用重新打一遍；填回的是任务原始全文，不是卡片上截断的那 5 行

界面没有"复制种子"这个按钮，也不提供手填种子。要复现某张图，用卡底的 🕒 加入队列生成（同种子）或 ↻ 再来一张（新种子）。种子在哪能看：大图弹窗和执行详情里有真实回读的种子值。

生成中长什么样

状态卡头卡片主体
排队中排队中 · 子工作流 档位一行「等待显卡空闲」，进度条空着
运行中生成中 · 子工作流 档位进度条 + 正在采样 · 6/8 步 + 已用 18 秒。这一步不显示预览小图
已完成已完成 · 子工作流 档位 用时 N 秒成品图 + 三个悬浮按钮 + 尺寸
失败失败 · 子工作流 档位红色卡，一句人话原因，展开看 ComfyUI 原文
已取消已取消 · 子工作流提示已取消，不可续跑，只能重新提交

1.4 右栏：ComfyUI 状态 + 本会话任务

块内容
ComfyUI连接地址（http://127.0.0.1:8188）、在线与否、队列里有几个任务在跑
本会话任务本次会话提交过的全部任务，每条前面一个勾选框、后面一个 ✕；顶部有总勾选框和 批量删除（N）

批量删除点下去会先弹确认框，确认后这些卡从会话里移出——和单条 ✕ 一样，只移出会话，不删文件。图片还在成果目录里，历史页照样能看到。

控件可选项说明

档位默认 / 快速（16:9） / 精细（16:9）档位是参数覆盖，名字后面括号里是画幅，选之前就能看出比例

发送 ↑—发送后输入框立刻清空，可以接着写下一句

@ 引用：让描述能指名道姓地用某张参考图

图生图上传参考图后，每张缩略图右下角有个 @。两个能力的「引用」表现不同：

  • 图片生成：点 @ 在描述框光标处插入引用 chip，写出来是 <image1>、<image2>；删掉 chip 后编号自动归位。这些令牌由 Qwen-Image 编码器识别「第几张图」。
  • 角色设定图：点 @ 把这张图加入描述框上方的「已引用」条（缩略图 + 图 N + ✕）。设定图靠「参考方式」（锁定同角色 / 只借画风）决定怎么用图，不用 <imageN> 令牌；点「基于上一条」会把这些缩略图一起带回来。
规则具体行为
编号顺序按参考图在界面上从左到右的顺序，从 <image1> 开始
删除后重新编号，不留空号
提交时令牌原样进服务端提示词，模型能识别"第几张图"
上限图片生成最多 3 张参考图（maxRefs: 3），超了不让加

1.7 大图弹窗

点成品图或 ⤢ 打开大图窗，里面有：完整原图、归档后的真实路径、种子行、按钮。路径显示的是归档之后的最终位置（成果目录/能力名/文件名），不是 ComfyUI 的临时输出路径。

  • ⤢ 放大：把预览窗放到接近全屏（四周留一点边，仍看得出是弹窗），再点变「⤡ 还原」。
  • 种子那一行右侧并排两个按钮：打开所在目录 和 下载 ⬇。
  • 弹窗里没有「复制图片」按钮；要复制图片本身，用卡片上的 ⧉，或在弹窗里按 Ctrl/⌘ + C（焦点不在输入框时）。

二、创作台：角色设定图

2.1 和图片生成是同一个创作台，换了一套输入区

中栏、右栏、任务卡、大图弹窗、历史全都一样，唯一变的是底部输入区：从「一句话 + 档位」变成「五行结构化选择」。因为角色设定图的参数不是一维的——版式、画法、参考方式三个维度互相组合，光靠档位下拉表达不清。

2.2 五行分别是什么

行选项行右侧那句说明（随选择变化）
版式四视图横排 16:9 / 四宫格 9:16 / 单张全身 9:16例：版式决定画幅：16:9 1536 × 864。选版式等于同时定了画幅，不用另外挑比例
画法彩色 / 线稿彩色：风格行用下面的「风格」。选线稿时风格行换成线稿风格句
参考锁定同角色 / 只借画风锁定同角色：图 1 就是这个人：不换人、不改性别；只借画风：图 1 只用来参考画风和笔触，不要照抄图 1 里的人物
档位默认（有的组合还有 快速 / 精细）默认就是这个组合的完整配方 · 出图 1536 × 864——默认档不可改，它是这个组合的原始配方
风格12 类预设 + 自定义…；进入页面 / 每次生成后默认选「自定义…」写实摄影 / 3D 动画 / 游戏概念 / 奇幻立绘 / 厚涂插画 / 水墨国风 / 日系赛璐璐 / 扁平矢量 / Q 版 / 绘本 / 古典油画 / 暗黑哥特。图生图时预设全部禁用，只能选自定义

输入区底部还有 ＋ 上传、收起提示词/看完整提示词、复制、发送 ↑。

图生图允许描述框为空。上传参考图后，不写角色描述也能点发送——提示词由版式句 + 参考声明组成，用于「单人图转四视图」「彩色图转线稿」这类纯转换；文生图仍必须写描述。图生图一张参考图都没有时照样拦下。

2.3 「组合」是什么：18 种选择，6 组档位

创作台里版式 × 画法 × 参考方式是相乘的关系，共 18 种选择，每种是一套完整配方（提示词段落 + 参考图用法 + 工作流 + 画幅）。但档位只有 6 组：按「版式 × 子功能（文生图 / 图生图）」分，因为画法（彩色/线稿）和参考（锁定同角色/只借画风）只改提示词、不改工作流的参数节点。所以同一版式下，无论画法/参考怎么切，看到的都是同一组档位（默认 / 快速 / 精细）。

模式组合数算式
文生图63 版式 × 2 画法（没有参考方式，因为不吃参考图）
图生图123 版式 × 2 画法 × 2 参考方式（锁定同角色 / 只借画风）
合计18 种选择 / 6 组档位创作台 18 种选择照旧；档位按 6 组共享，管理台档位表也只列 6 组

选文生图时，「参考」那一行不出选项，只有一句提示：文生图不吃参考图；要锁角色 / 借画风就切到「图生图」。——不是禁用了，是这个维度在这一支里不存在。

图生图模式下，模式分段旁边还有一句 拿现有角色图重画成设定图，说清图生图在这里的用途。

2.4 提示词预览与复制

点 看完整提示词 会在输入区上方展开一条预览，里面是把「版式模板 + 通用块 + 风格句 + 你写的描述」拼起来的完整提示词，和提交给 ComfyUI 的是同一份（都走 promptlib.compose()，前端不另拼）。

按钮行为
看完整提示词 / 收起提示词展开 / 收起预览。展开后按钮文字跟着变
复制把整条提示词复制到剪贴板，可以拿去别处用

三、生成历史

3.1 一页网格看完所有成品

顶栏点 🗂 历史 进来。所有生成过的成品按时间倒序铺成网格，跨能力合并在一起——图片生成和角色设定图的成品在同一个列表里。

3.2 两个筛选

筛选选项
按能力全部 / 图片生成 / 角色设定图（只列已配置的能力）
按日期全部 / 今天 / 近 7 天

两个筛选可以叠加。筛完的视图会记在服务端状态里，刷新页面回来还是这个筛选。

3.3 多选、批量下载、删除

控件行为
每张卡左上角的勾选框选中 / 取消选中一张，按钮上的数字实时变
顶部总勾选框全选当前筛选下的全部成品 / 取消全选
⬇ 批量下载（N）把选中的 N 张打成一个 zip 下载。没选时按钮上是 0
🗑 删除（N）删除选中的记录，先弹确认框
每张卡右上角 ✕删单张，同样先确认

历史页的「删除」和创作台的「移出会话」不是一回事：历史删除会真的删掉这条记录（带确认），创作台的 ✕ 只是把卡片从本次会话里收起来。

四、管理台

4.1 左边四页，档位表下面还挂子菜单

菜单项作用
1 能力与工作流所有能力的总览与启用开关，进各能力配置的入口

底部有一行「N 个能力可用」的统计。左栏最上面是 🗂 历史，和创作台共用。

4.2 页面一：能力与工作流

17 个能力一行一个，每行显示图标、名称、状态标记、一句话描述，右边是配置按钮。

列内容
状态标记可用 或 未配置
规模信息可用能力显示 3 档可选（图片生成）或 18 种选择 · 6 组档位（角色设定图）；未配置的显示「还没排档位」

4.3 页面二：档位表

这是一个能力的参数控制台。上面是切换带，下面是五步结构。

顶部切换带

行内容说明
子功能图片生成：文生图 / 参考生图
角色设定图：文生图 / 图生图		每个子功能各一组档位
版式四视图横排 / 四宫格 / 单张全身子功能 × 版式 = 6 组档位。画法/参考不再出现在档位表（只改提示词，参数一样），创作台里照旧能选
当前版式 · 子功能 + 标签 + ↻ 重读档位 + ✎ 设定图模板 + 去创作台试这个组合白框那一条：左边标签写清楚现在选的是谁、画幅多少，右边三个按钮是操作

三个按钮的分工：↻ 重读档位 把档位配置重新读一遍；✎ 设定图模板 以模态框打开提示词库（模板只是角色设定图的子功能，不再是全局菜单页）；去创作台试这个组合 直接跳回创作台、把能力、模式、版式、画法、参考、档位、风格一次性对上。角色设定图档位表支持拖拽已有档位改变顺序（默认档固定，和图片生成一样）。

五步结构

步骤里面是什么怎么用
① 工作流文件这个子工作流对应的 JSON 文件名（在 workflows/ComfyBridge/ 下）只读，让人知道改的是哪个文件
② 参数节点 N 个工作流里所有可调节点，逐行列出节点 id 和 class 名，前面带勾选框勾上=这个节点进档位。id 用等宽字体单独一列，长 id 不换行、不压到 class 名
③ 不用设的节点 N 个已在配置里被排除的节点点「移出」可以把节点放回 ②
④ 新增档位把刚勾上的节点里的参数挑出来，填名字和值填完点 ＋ 添加 生成一条新档位
⑤ 已有档位 N 档档位列表，一行一条：序号、拖动点、N 项改动、生效画幅、✎ 编辑 / 👁 查看、✕名字就地改；改动项数是和默认档比出来的；拖动点可以调顺序

「默认」档是只读的。它就是这个组合的原始配方，删不掉（点了会提示不可删）、名字改不了、参数也不能动。所有自定义档位都是相对它做参数覆盖。

页面右上角是 ← 返回列表 和 保存。改完必须点保存才写回配置文件。

4.4 设定图模板（档位表里的模态框）

只有角色设定图用得上：管的是提示词库，不是参数。它不再是管理台左栏的独立页面，而是从「档位表 → 角色设定图」顶部的 ✎ 设定图模板 按钮以模态框打开（因为它只是角色设定图的子功能）。

块规模干什么
档位与画幅2 个子工作流看每个子工作流的创作台选择数、6 组档位和出图尺寸；去档位表调参数 跳到档位表。档位按组共享，不按 18 种选择各存一份
版式模板3 个（16:9 四视图横排、9:16 四宫格、9:16 单张全身）每个版式一段模板文字。带 预览整条提示词（看这一版拼出来是什么）和 填入创作台（把这一版带到创作台试）
通用块6 段，只读不管什么版式都要带上的硬要求：分栏要求、分格要求、同一个人、不要投影、正面平光、不要分割线/边框/网格……固定配方，不能在这里改
线稿风格句4 条，只读画法选「线稿」时用的风格描述（工业设计草图 / 美式动画勾线 / 铅笔线稿等），和彩色风格是两套；固定配方，不能改
风格预设12 类，唯一可编辑每类一个名字 + 一段描述，就是创作台「风格」下拉里的那些。可以改名、改描述，也能 ＋ 新增预设 / ✕ 删除预设
已实测组合15 条验证过能出好结果的组合清单，每条可以 填入 直接带到创作台

↻ 重读提示词库（把 prompts/ 下的文件重读一遍）和 保存 都在「风格预设」区块里。底部原来重复的「保存提示词库」已去掉（和「保存」功能重叠）。

五、能力库与状态

5.1 三种状态

状态判定标准界面上长什么样
可用启用 + 至少挂了一个工作流 + 有可用档位左栏正常黑字，可点进创作界面；管理台标 可用 并给 配置 按钮

5.2 启用开关

管理台「能力与工作流」每行右边的开关可以当场开/关。关掉后创作台左栏不再显示这个能力，但它的档位、工作流文件、提示词库都原样保留，重新打开就回来。

六、外部接口（给 AI 用）

6.1 三个必需接口

用途接口说明
问有什么能力GET /api/v1/capabilities返回能力清单，含每个能力的参数说明和可选档位
下单POST /api/v1/orders传能力 id + 参数，返回任务 id
取货GET /api/v1/orders/{id}查状态和成品地址

6.2 配套的小接口

接口干什么
GET /api/v1/health探活
POST /api/v1/uploads传参考图，拿 ref id
POST /api/v1/precheck先检查这次提交会不会被拦，不真的下单
POST /api/v1/orders/{id}/cancel取消
GET /api/v1/tasks列出任务
GET /api/v1/files/{run}/{index}取成品文件
GET /api/v1/skill取技能说明书原文

6.3 失败时说人话

所有接口失败都返回 {"ok": false, "reason": "一句中文原因"}。原因不是堆栈，是「ComfyUI 没启动」「参考图超过 3 张」这种能直接转述给人的话。

七、技能（给 AI 的说明书）

7.1 技能里写什么

内容作用
能力清单与参数告诉 AI 有哪些能力、每个参数的取值范围
什么时候用哪个能力例：要人物多视角设定图就走角色设定图，不要用图片生成拼
调用顺序先 capabilities 再 orders 再轮询 orders/{id}
失败怎么转述把 reason 原样说给用户，不要自己编

7.2 一个完整对话长什么样

用户：帮我生成一张赛博朋克风格的竖图

AI →（查能力）→ 选 image.generate，模式文生图，档位「默认」

AI →（下单）→ 拿到任务 id →（轮询）→ 状态 done → 把成品地址和图片给用户

一次下单只出一件事，不要在一次调用里塞多个意图。
