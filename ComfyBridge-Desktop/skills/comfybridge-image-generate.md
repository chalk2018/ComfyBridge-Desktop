# ComfyBridge 图片生成技能

在支持斜线技能的 AI 客户端里选中本技能，用一句自然语言描述需求即可出图。应用会自己挑工作流、填参数、盯进度、取回成品并归档。

## 四步流程

1. **看菜单**：调用看菜单接口，拿到当前可用的能力、档位和素材要求。1.01 只有「图片生成」，档位名以菜单返回的为准。
2. **上传素材**（可选）：用户给了参考图，先上传，记住返回的引用编号；没有图就跳过。
3. **下单**：用自然语言描述画面，选一个档位，附上参考图编号。返回任务编号和建议的轮询间隔。若返回「忙」，把"谁在跑、跑到几成"原样转述给用户，不要重试、不要排队。
4. **取货**：按建议间隔查询任务，直到出片或失败。把成品地址展示给用户；失败时只说人话原因，原始报错等用户要看再展开。

## 六条禁令

- 不实现也不调用 MCP 端点；接入方式只有斜线技能这一种。
- 不读取工作流 JSON、不读取配置文件、不扫描模型目录，也不写脚本去拼节点图。
- 不向用户暴露步数、CFG、采样器、种子、模型文件名等技术参数；用户只说描述和档位名。
- 不替用户预设或生成种子；种子由 ComfyUI 执行时决定，应用事后回读，卡底显示的必须是回读值。
- 不在 ComfyUI 忙时把普通生成塞进队列、不自动换工作流、不因为显存不足降档重试。
- 不把 HTTP 接口当对外接入方式宣传，不写对接文档、不做命令行工具或浏览器插件。

## 失败时转达

- 没连上 → 请先启动 ComfyUI。
- 工作流被拒 / 执行报错 → 说清哪一步失败，附一句"可以重试一次"。
- 归档失败 → 成品照常给，只补一句"归档没成功，原路径是 …"。
- 暂时没匹配的工作流 → 说清"这种情况还不支持"。

技能只需要三类请求：看菜单、下单、取货；上传、预检、取消、任务列表、取文件、健康检查是配套的小接口。
