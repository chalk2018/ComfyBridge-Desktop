## 七、本轮发现并修复的问题

| # | 问题 | 修复 |
| --- | --- | --- |
| 1 | `VideoPayload` 无 `duration`，前端时长被静默丢弃 | 增加 `duration: float | None`，`video_info` 透传，`services.video_opt` 按 24fps 折算帧数 |
| 2 | 视频提交误用画面默认 `ratio/res/steps`，自建挡位失效 | 创作台与画布均改为从选中档位读取三项参数 |
| 3 | 图片生成管理台缺「设定图模板」入口，绑定会误开角色库 | `wfPickBar` 增加按钮，`bindAdmin` 对 `image.generate` 打开通用模板 |
| 4 | 新增视频档默认采样步数为 8 | 改为 4（含前端 fallback） |
| 5 | 图片生成布局顺序与设定图不一致、缺完整提示词 | 改为画法 → 档位 → 风格 + 服务端同源预览 |
| 6 | 画布结果卡放大调用签名错误 `openZoom('', r.id)` | 改为 `openZoom(jobId + '|' + runId)` 并补下载按钮 |
| 7 | 画布图片节点缺画法/风格，视频节点仍有三下拉 | 图片节点补画法/风格/一句话风格，视频节点参数全部走共用挡位 |
| 8 | 画布管理页仍有独立视频/音频挡位表 | 删除两块，改成挡位共用说明；侧栏「档位表」排除画布 |
| 9 | 管理台音频未合并 | 新增 `pageAudioGrades` 四 tab 页面与读写绑定 |
| 10 | 跨能力定位失败 | 定位按钮先切到任务所属能力再滚动高亮 |
| 11 | 时长滑条输入被轮询写回旧值 | 时长 handler 不再持有旧闭包对象，每次写当前 `videoForm()` |
