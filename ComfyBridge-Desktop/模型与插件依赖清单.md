# ComfyBridge 模型与插件依赖清单

- **ComfyUI ≥ 0.42.1**。

## 2. 自定义节点（7 个）

| 插件 | 提供的节点 | 影响的能力 | 仓库 |
|---|---|---|---|
| ComfyUI-Impact-Pack | `ImpactSwitch` | 视频生成扩展 | https://github.com/ltdrdata/ComfyUI-Impact-Pack |

| ComfyUI_Comfyroll_CustomNodes | `CR Prompt Text` | 视频生成扩展 | https://github.com/RockOfFire/ComfyUI_Comfyroll_CustomNodes |
| Derfuu_ComfyUI_ModdedNodes | `DF_Int_to_Float` | 视频生成扩展 | https://github.com/Derfuu/Derfuu_ComfyUI_ModdedNodes |
| TE-Speed-MiniMaxH3-OSS | `TESpeedMiniMaxH3` | 视频生成扩展（4/8/20 采加速链） | https://github.com/HELPMEEADICE/TE-Speed-MiniMaxH3-OSS |
| comfyui-AICG3D | `SparkTTSRun`、`SparkTTSClone` | 音频生成 → 语音生成 / 声音克隆 | https://github.com/JGRFW/comfyui-AICG3D |

补充说明：

- 前 6 个只被 **5 个「视频扩展-多参极速生视频」工作流**引用；不装的话，其余能力照常可用，只有视频扩展会缺节点。
- `comfyui-AICG3D` 只被 **「音频-语音生成」「音频-声音克隆」** 两个工作流引用，且它内部还依赖一个外部模型（见第 4 节缺失项）。
- 其余节点（`UNETLoader`、`CLIPLoader`、`VAELoader`、`SamplerCustomAdvanced`、`LoadImage`、`SaveVideo` 等）都是 ComfyUI 内置，不需要额外安装。

安装方式（三种任选）：

1. ComfyUI Manager → Install Custom Nodes → 搜索插件名安装；
2. `ComfyUI/custom_nodes` 下 `git clone` 上表仓库，再重启 ComfyUI；
3. 便携版/Desktop 版直接拖入插件目录后重启。

## 4. 当前缺失项（会影响功能）

| 缺失项 | 影响的界面 | 补齐方式 |
|---|---|---|
| **Spark-TTS-0.5B 模型** | 音频生成 → 语音生成、声音克隆 | 下载 https://huggingface.co/SparkAudio/Spark-TTS-0.5B ，把整个目录放到 `ComfyUI/models/tts/Spark-TTS-0.5B`（内部需包含 `LLM/`、tokenizer 等完整文件），重启 ComfyUI |

`comfyui-AICG3D` 插件本身已装好、节点也能加载，但它在首次运行时会检查 `models/tts/Spark-TTS-0.5B`；当前该目录为空，因此这两个子功能会报「缺少 Spark-TTS-0.5B 模型」。

## 5. 能力 → 依赖对照表

| 能力 | 必需插件 | 必需模型 |
|---|---|---|
| 图片生成 / 角色设定图 / 场景设定图 / 道具设定图 / 宫格分镜故事板 | 无（纯内置） | 3.1 图像 5 个文件 |
| 视频生成（文生 / 首尾帧 / 参考 / 故事板） | 无（纯内置） | 3.2 中 fl2va、ref2va、qwen3vl_32b、int8 视频 VAE、audio VAE、4 个 LoRA |
| 视频生成扩展（4/8/20 采 × 480P/768P） | Impact / KJNodes / MieNodes / Comfyroll / Derfuu / TE-Speed | 3.2 中 fl2va、qwen3vl_32b、**fp16** 视频 VAE、audio VAE、4 个 LoRA |
| 音频 → 音乐生成 | 无（纯内置） | minimax_music3 三件套 |
| 音频 → 参考生成音乐 | 无（纯内置） | yue2_3b + sheetsage2 |
| 音频 → 语音生成 / 声音克隆 | comfyui-AICG3D | **Spark-TTS-0.5B（当前缺失）** |
| 视频生成画布（暂未推送） | 无（复用图片 / 视频工作流） | 同上 |

工作流档位与模型的对应（视频扩展）：

- 4 采 480P / 8 采 480P / 8 采 768P：使用对应的 turbo LoRA（4step 或 8step）；
- 20 采 480P / 20 采 768P：不挂 LoRA，走原模型 20 步。

## 6. 搭建与校验步骤

1. **装 ComfyUI 0.42.1**（Desktop 或便携版均可，确认 `GET /system_stats` 里的 `comfyui_version` ≥ 0.42.1）。
2. **装 7 个自定义节点**（第 2 节），装完重启 ComfyUI。
3. **放模型**（第 3 节）：按「目录 → 文件」放入模型根目录对应的子文件夹（`diffusion_models` / `text_encoders` / `vae` / `loras` / `checkpoints` / `audio_encoders`）。
4. **补 Spark-TTS-0.5B**（第 4 节），否则语音与克隆不可用。
5. **重启 ComfyUI**，然后校验：

```bash
# 版本
curl http://127.0.0.1:8188/system_stats

# 节点是否齐全（能返回 JSON 即已注册）
curl http://127.0.0.1:8188/object_info/TESpeedMiniMaxH3
curl http://127.0.0.1:8188/object_info/SparkTTSRun

# 模型是否被识别
curl http://127.0.0.1:8188/models/diffusion_models
curl http://127.0.0.1:8188/models/loras
curl http://127.0.0.1:8188/models/tts
```

6. 启动 ComfyBridge，进「图片生成」跑一张；再分别试一条视频、一条音乐，确认三条链路都通。

## 7. 维护说明

- 新增或替换工作流后，重新统计节点与模型：扫描 `workflows/*.json` 中的 `class_type` 与 `*_name` 字段，再用 `/object_info` 反查归属插件。
- 修改了模型文件名时，记得同步 `config.yaml` 的 `videoExt.models` 分档映射。
- 本文件随 ComfyUI 版本升级需要复核，尤其是 `comfy_extras` 节点改名的情况。
