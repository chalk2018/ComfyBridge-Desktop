# ComfyBridge 1.04

本机 ComfyUI 转接服务：一个 Python 进程、一个端口，带创作台、管理台、历史记录和给斜线技能用的接口。1.04 在 1.03 基础上新增「视频生成」「音频生成」与「视频生成画布」，图片侧能力与 1.03 完全一致。

## 这一版（1.02）改了什么

- **能力清单固定死**：能力与工作流页去掉卡片上的复制（⧉）/删除（✕）按钮，也去掉页面右上角的「重读配置」。改能力请改 `config.yaml` 后重启。
- **档位表加子菜单**：管理台左侧「档位表」下面直接挂着图片生成 / 角色设定图，点一下直达，不用先进列表再点「配置」。
- **两张档位表长得一样了**：图片生成也补上白框切换带 +「↻ 重读档位」+「去创作台试这个组合」，与角色设定图完全同构。
- **内置档改名「默认」**：管理台和创作台里原来叫「母版」的那一档，现在统一叫「默认」（它就是组合的完整配方，只读、不可删）。代码里仍用 `MASTER`，同时拦着用户自建同名档位。
- **手机端重排**（≤820px，桌面一律不变）：顶栏收成图标 + ☰ 左侧抽屉；右栏「状态与任务」改成右侧滑出、占屏约三分之一，全选/批量删除变图标按钮；能力卡片开关与配置挪到右侧同一行；档位表分段按钮自动换行、保存靠右；设定图模板的「已实测组合」在手机上变成卡片（不再竖排）；历史页换相册图标；标题区补上运行状态。
- **手机端三处收尾**：顶栏改为「菜单最左、状态正中」（状态只报「已连接/未连接 + 空闲/生成中」）；左抽屉高度写死 `100dvh`，占满整个竖屏（之前只按内容撑开，下半屏空着像缺了一块）；输入区最高半屏、中间内容区独立滚动，底栏按钮常驻可见。
- **导航竞态修复**：切页时先把 `_navPending` 立起来再 await，否则 ComfyUI 响应慢（3 秒超时）时每秒轮询会把页面拽回上一页——表现为「点自检又弹回服务设置」。同时 `autoDiag()` 改成按长度判空，避免空结果永久卡死不再重查。
- **ComfyUI 连接自愈**：`ComfyClient.health()` 第一次失败就换一只 httpx 连接池再试一次。ComfyUI 重启后旧 keep-alive 连接全失效，以前只能重启本服务才恢复，现在自动恢复。
- 需求文档同步升到 1.02（`../ComfyBridge-需求与功能文档-1.02.html`）：第 03 / 08 章按当前画面重写，内嵌 19 张真实界面截图，旧的手绘页面示意图全部替换；原型文件未动。

## 这一版（1.03）新增了什么

- **场景设定图**：文生图 / 图生图 / 扩图三种模式；文生图与图生图支持普通、全景、鸟瞰、四宫格、九宫格；扩图支持推镜短/长、拉镜短/长、左转 45°/75°、右转 45°/75°。图生图/扩图有参考图、全景图、鸟瞰布局图、布局草图四个槽位，扩图参考图必传、提示词可空；文生图/图生图支持彩色/线稿与禁角色开关，扩图完全基于参考图。
- **道具设定图**：与角色设定图同构，只有多视图 / 单视图两种版式；多视图按视角数量自动一排或两排，单视图为纯白底居中道具。
- **提示词独立可调**：场景/道具各有自己的提示词库 `prompts/scene_sheet.json`、`prompts/prop_sheet.json`，同名 12 类风格改成场景化/道具化措辞；调通记录见 `设定图1.03_提示词调通文档.md`。
- **管理台同步**：档位表子菜单增加场景/道具设定图，沿用组合×档位机制；「✎ 设定图模板」按能力打开各自的提示词库，可编辑风格预设。
- **母版口径**：子功能 × 版式 = 一个工作流母版（场景 5+5+3、道具 2+2，共 17 个母版 / 59 个组合）。扩图的短/长与左右转角度是**子选项**，只改提示词里的机位句，不新增母版、不进档位表；画法、禁角色、风格同样只改提示词。
- **宫格分镜故事板**：一个能力覆盖四/六/九宫格三种版式，逐格写镜头描述（左侧宫格小按钮切格、右侧输入框写这一格），空格子在成图里保持纯白；画法支持彩色 / 线稿，0~6 张参考图，格子里写「图 1」即锁定该参考图的角色身份。提示词库独立为 `prompts/board_story.json`，调通记录见 `宫格分镜故事板_提示词调通文档.md`，功能测试见 `宫格分镜故事板_功能测试报告.md`。

## 这一版（1.04）新增了什么

- **视频生成**：八种模式并排（文生视频 / 首尾帧生视频 / 参考生视频 / 故事板生视频可用；角色替换 / 动作迁移 / 白膜生视频 / 长视频占位禁用）。比例 16:9 / 9:16，分辨率 480P / 768P，步数 4 / 8 / 20。步数与 LoRA 挂钩：**4 步挂 4 步加速 LoRA（参考生视频用 ref2v，首尾帧用 fl2v）、8 步挂 8 步 LoRA、20 步不挂 LoRA**。文生视频与首尾帧走 `fl2va`，参考与故事板走 `ref2va`，都是 H3。文生视频不接受素材；参考生视频可传图 / 视频 / 音频，`@` 引用后自动转成 H3 的 `<Picture N>` / `<Video N>` / `<Audio N>`；首尾帧两个上传位（至少一张）；故事板一个上传位 + 四 / 六 / 九宫格单选 + 可再传参考，**允许不写提示词**。
- **音频生成**：音乐生成 / 参考生成音乐 / 语音生成 / 声音克隆四个功能页，模式、档位、歌词、时长、参考音频各自独立；成品在卡片里就是播放器，带真实时长。
- **视频生成画布**：无限画布，五类节点（图片 / 视频 / 音频素材节点、图片生成 / 视频生成节点）。生成节点上半是结果（图片：看大图 / 再来一张 / 队列生成；视频：播放器），下半是提示词，不设文生图 / 图生图选项；素材节点左侧无连接点，生成节点左右都有，**图片生成节点左侧只接图片**。空白处双击或把连线拖到空白都会弹出「生成节点」菜单，后者选完自动连到新节点左侧；点连线中点出现剪刀，点一下删掉这条线。上游节点（含刚生成的成品）在生成节点里显示为带 A/B/C 角标和 `@` 按钮的小缩略图，`@` 把 `[图 N]` 插到光标处。允许零参考纯提示词出图出片。
- **管理台**：「视频生成画布」页改成两个子功能（图片生成 / 视频生成）各配一条工作流；档位表增加视频四模式与音频四能力的档位，视频档位直接决定比例 / 分辨率 / 步数 / LoRA。
- **七处改修**：生成时结果区自动滚到最新一块；图片生成补「画法（彩色 / 线稿）」与「风格（含自定义，图生图只支持自定义）」；管理台「返回」回到进来之前那一页（从画布进来就回画布，1.03 会把人扔回创作台）；窗口从全屏缩到手机宽布局不崩；左右栏任何尺寸都能展开 / 合并（手机外默认展开）；任务栏勾选框与文字块垂直居中对齐，点整行即选中（删除 / 定位按钮除外）；「本会话任务」改成全局的「会话任务」。

## 在另一台电脑上搭建（clone → 能跑）

仓库里只有源码，**不含 `.venv`、`.cache`，`data` 里也不带历史任务和上传图**。所以别人拉下来后要先建环境，再启动。

### 1. 前置条件

| 项 | 要求 | 说明 |
| --- | --- | --- |
| 系统 | Windows 10 / 11 | 启动脚本是 `.bat`；目录选择框依赖 PowerShell |
| Python | 3.12.x（3.10 以上可用） | 安装时勾选 `Add python.exe to PATH` |
| ComfyUI | 已装好并能启动 | 默认 `http://127.0.0.1:8188`；工作流用到的模型、自定义节点必须已装在本机，否则任务会报节点/模型缺失 |
| ffmpeg（可选） | `ffprobe` 在 PATH 里 | 用来读音频/视频成品时长；没有也能跑，只是时长显示不全 |

### 2. 获取代码

```powershell
git clone https://github.com/chalk2018/ComfyBridge-Desktop.git
cd ComfyBridge-Desktop
```

没有 git 的话，在网页上 `Code → Download ZIP`，解压后进入目录。

### 3. 建虚拟环境并装依赖（只需一次）

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

- 虚拟环境目录名必须是 `.venv` —— `启动服务.bat` 里固定调用 `.venv\Scripts\python.exe`
- 国内网络慢可以加镜像：`-i https://pypi.tuna.tsinghua.edu.cn/simple`
- 依赖很少（fastapi / uvicorn / httpx / pyyaml / python-multipart / websocket-client / pillow），几分钟装完

### 4. 启动

双击 `启动服务.bat`（或 `start.bat`，两者等价），然后浏览器打开 <http://127.0.0.1:8190>。

命令行等价：

```powershell
.\.venv\Scripts\python.exe run.py
```

关掉控制台窗口就等于停止服务。启动前会做端口预检，端口被占用时会直接给中文提示。

### 5. 首次必做配置（只改一处）

页面 → 管理台 → 服务设置 → 成品存放：

1. 点「ComfyUI 输出目录」右边的 **添加目录**，在弹出的窗口里选中你本机 ComfyUI 的 `output` 文件夹（例如 `D:\ComfyUI\output`）
2. 点「保存并生效」

成果目录会自动等于 `<输出目录>/ComfyBridgeOutput`，不用填也不用手动建，保存时自动创建。

如果 ComfyUI 不在 `127.0.0.1:8188`，在同一页把「ComfyUI 地址」改成实际地址。

> 不配也能启动，但顶部会一直显示红条「ComfyUI 输出目录不存在或不是文件夹」，而且出图后成品拷不进成果目录。

### 6. 关于 data / .cache（为什么一开始是空的）

- `data/uploads`、`data/tasks`、`data/trash` 在启动时自动创建为**空目录**；历史任务、上传图、成品路径都不会跟着仓库走
- 首次打开时任务列表、历史记录、上传区都是空的，这是正常的，从零开始用即可
- `.cache`（临时文件、日志、按档位生成的工作流拷贝）同样自动生成，不入库
- 所有写入都限制在应用文件夹内：`启动服务.bat` 会把 `TEMP` / `TMP` 指到 `.cache\tmp`

### 7. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 双击窗口一闪就没 / 提示找不到 python.exe | 没建 `.venv`，回到第 3 步 |
| 控制台报 `[Errno 10048]` 或提示端口被占用 | 已经有一个 ComfyBridge 窗口开着，先关掉；或到管理台改端口 |
| 顶部红条「ComfyUI 输出目录不存在」 | 用「添加目录」重新选 output 目录，再保存并生效 |
| 创作台提示未连接 ComfyUI | 先把 ComfyUI 启动起来（默认 8188） |
| 页面还是旧界面 | `Ctrl + F5` 强刷，浏览器缓存了 `app.js` |
| 点「添加目录」没反应 | 服务必须在你自己的桌面会话里启动（双击 bat）；用计划任务/服务方式拉起的进程弹不出窗口 |
| pip 安装很慢或超时 | 加 `-i https://pypi.tuna.tsinghua.edu.cn/simple` |

## 运行（双击启动）

前提：本机 ComfyUI 已启动（默认 `http://127.0.0.1:8188`），且已加载 Qwen Image 2.1 Turbo 的两个工作流所需模型。

**双击 `启动服务.bat`**（或英文名 `start.bat`，两者完全等价）即可：

- 弹出一个黑色控制台窗口，服务日志与任何错误信息都直接打印在窗口里；
- 浏览器打开 <http://127.0.0.1:8190> 使用创作台与管理台；
- **关掉这个黑窗口，服务就停了**；
- 万一启动失败，窗口会停在 `Service stopped. Exit code: ...` 并等待按键，报错不会一闪而过；
- 启动前先做端口预检：端口被另一个 ComfyBridge 窗口占用时，窗口里直接给中文说明，不会只甩一串英文 `[Errno 10048]`。

命令行方式（等价）：

```powershell
cd <应用所在目录>
.\.venv\Scripts\python.exe run.py
```

允许手机/局域网访问：管理台 → 服务设置 → 打开「允许本机以外访问」，保存后重启应用（监听地址改动需要重启）。

换机器 / 别人 clone 后怎么从零装好，见上一节「在另一台电脑上搭建」。

## 十四个真实工作流

图片侧六条沿用 1.03 的母版（见下表）。1.04 新增八条：视频四条、音频四条，均由 `tools/build_video_audio_wf.py` 生成，`tools/validate_wf.py` 对着 ComfyUI `/object_info` 静态校验过（class_type / 必填输入 / 连线下标 / 枚举值 6/6 通过）。

| 母版 | 关键节点 | 应用内工作流 |
| --- | --- | --- |
| 文生视频 | `MiniMaxH3ReferenceToVideo`（fl2va）+ 步数/LoRA 双开关 | `workflows/视频生成-文生视频-h3.json` |
| 首尾帧生视频 | 同上，`ref_images` 两个槽位当首帧 / 尾帧 | `workflows/视频生成-首尾帧生视频-h3.json` |
| 参考生视频 | 同上（ref2va），图片 / 视频 / 音频各一组 autogrow 槽 | `workflows/视频生成-参考生视频-h3.json` |
| 故事板生视频 | 同上，故事板整图进第一个图槽 | `workflows/视频生成-故事板生视频-h3.json` |
| 音乐生成 | `MiniMaxMusic3TextEncode` + `EmptyMiniMaxMusic3LatentAudio` + KSampler + `SaveAudio` | `workflows/音频-音乐生成.json` |
| 参考生成音乐 | `SheetSage2AudioToABC` + `YuE2GenerateMusic` | `workflows/音频-参考生成音乐.json` |
| 语音生成 | `SparkTTSRun` | `workflows/音频-语音生成.json` |
| 声音克隆 | `SparkTTSClone` | `workflows/音频-声音克隆.json` |

四条视频工作流的注入点是 `video_ref`：提示词、宽高、帧数（124 帧 / 24fps ≈ 5.17s）、`switch`（步数是否走加速）、`steps` / `base_steps`、`lora_switch` + `use8`（4 步切 lora4、8 步切 lora8、20 步直连原模型）。音频注入点是 `lyrics_target` / `duration_target` / `audio_ref`，语音与克隆另有性别 / 年龄 / 音高 / 语速的参数覆盖。

## 角色设定图的提示词库

设定图的整条提示词（通用块 U1~U5 + 参考声明 R1/R2 + 版式描述 + 画法句 + 两行变量）不写在代码里，而是数据文件 `prompts/character_sheet.json`，由 `app/promptlib.py` 唯一负责拼装：

- 创作台的「看完整提示词」、提交时真正发给 ComfyUI 的正文、管理台「设定图模板」页编辑的内容，走的是同一个 `compose()`，不会出现「页面看到的和实际跑的不一样」；
- 管理台 → 设定图模板 可以直接改通用块、线稿句、风格预设，保存即写回该 JSON，组装结果立刻跟着变；填错（比如某块留空）会被拦下并指出是哪一块；
- 「组合」是配方的唯一口径：`版式 × 画法 × 参考方式` 一共 18 个组合（文生图 3 版式 × 2 画法 = 6，图生图再多 ×2 种参考方式 = 12），每个组合就是一条母版配方（工作流 + 提示词 + 画幅都定死），id 形如 `C.line.lock`；
- 版式只决定画幅与版式句，不再兼职档位名：点四宫格就是切到「四宫格」这个组合，档位仍然停在母版；
- 12 类画风、4 条线稿句都在这个文件里，改文案不用碰代码；画法＝线稿时，风格行仍整行换成线稿句，用户选的画风另起一行「造型气质」只借造型比例与线条节奏（`line_style_profiles` / `line_style_overlay`），不把上色、光影、材质词带进黑白线稿，避免「选了画风却完全不生效」。

## 组合与档位

档位是**挂在组合上的参数覆盖**，不是另一条配方：

- 母版 = 组合本身，参数由「版式画幅 + 组合」算出来，不落盘；`config.yaml` 的 `sheetGrades` 只存用户自建档位；
- 自建档位（如「快速」「精细」）只能改采样参数——`aspect_ratio` / `megapixels` / `multiple` / `cfg` / `sigmas`，**提示词一个字都不变**；
- 生效方式是 overlay：`effective_params = 母版画幅参数 + 档位参数`，按节点/字段合并，没写的字段继承母版；
- 档位跨组合隔离：档位名只在它所在的组合下有效，换个组合就自动回母版，绝不会「换档变成换配方」；
- 工作流拷贝按 `组合__档位` 打 tag 缓存，不同组合下的同名档位不会互相串味。

所以「加入队列生成」可以放心用：同一条任务换一档重跑，提示词、参考图、工作流完全一致，只有尺寸/步数变化——出来的就是同一张图的草稿版或高清版。

## 参数生效与删除

- **参数一定生效**：每次生成都按当前组合 + 档位重建工作流拷贝（页面改、手改 `config.yaml`、点「重读配置」都生效），并解决「宽高比」与「固定宽高」互相覆盖导致出图仍是 1:1 的冲突。档位表每档显示实际出图尺寸与逐参数核对结果（「参数已生效 / 有参数没生效」）；创作台档位按钮也带尺寸说明，每条任务记录实际使用的组合、档位与参数。
- **历史记录**：新增「全选」与「删除」（也可单张删）；删除会二次确认，然后**同时删掉本地对应的成品文件**，并从主页面移除这几张图。
- **会话任务**：右栏「本会话任务」和主页面对话卡片都能删除这条对话记录，**不删成品文件**；成品仍留在历史记录里，只有历史页的删除才真正删文件。
- **参考图不随移除立刻删文件**：要留给「基于上一条」复用；清理只按「草稿 + 未删会话任务引用的磁盘路径」保护后回收，所以重启或重新登记参考图都不会把还要用的图当孤儿删掉。

## 角色设定图的使用方式

创作台左栏「设定图」分组 → 角色设定图：

1. 选**版式**：四视图横排（1536×864）/ 四宫格（864×1536）/ 单张全身（864×1536）；
2. 选**画法**：彩色（用下面选的风格）/ 线稿（再选一种线稿句，针管笔 / 工业细线 / 美式细勾线 / 铅笔）；
3. 图生图时选**参考方式**：锁定同角色（不换人、不改性别）/ 只借画风（人物照文字新写）；
4. 写**角色描述**：年龄身份 + 脸型五官 + 发型发色 + 服装分件 + 2~3 个标志物；
5. 选**风格**（12 类实测画风，或「自定义…」自己写一句）；
6. 选**档位**：默认「母版」，也可以选你在管理台为这个组合建的「快速 / 精细」等（只改参数，提示词不变）；
7. 点「看完整提示词」能先看整条组装稿（可复制），回车/↑ 发送。

上面 1~3 三行选完就是一个组合，页面会直接显示这个组合的画幅与档位可选项。对话卡片上显示的是摘要（组合名 · 档位 · 角色行前段）而不是 800 字正文，点「看完整提示词」可看全文；历史卡片和「基于上一条」都会把版式/画法/参考方式/档位/角色行带回来。

管理台 →「档位表」的版式和交互与「图片生成」档位表一致：**顶部**用「子功能 / 版式 / 画法 / 参考 / 当前」五行横向分段按钮拼出组合（和创作台一样点着切，18 个组合都能拼出来）；**左栏** ① 工作流文件（只读）、② 可设置的参数节点（`502` / `459_507` / `459_502`，勾了 ④ 才出现对应参数）、③ 不用设的节点（含「宽高比 aspect_ratio · 版式定」，画幅跟着版式走）；**右栏** ④ 在上新增档位、⑤ 在下显示已有档位（母版只读，其余可改名/改参数/删除，逐参数核对「配置值 → 实际提交值」）。右上角「保存」整表回写，「重读档位」重新拉配置，「去创作台试这个组合」把版式/画法/参考方式一次带回创作台。「设定图模板」页仍负责通用块、线稿句、风格预设的文案编辑，并能「填入创作台」复现任一组合。

## 宫格分镜故事板

创作台左栏「故事板」分组 → 宫格分镜故事板。一个能力管三种版式：

1. 选**版式**：四宫格（2×2，1536×864）/ 六宫格（3×2，2304×864）/ 九宫格（3×3，1536×864），每小格都是 16:9；
2. 选**画法**：彩色 / 线稿（线稿再选 W1~W4 一种线稿句），整张统一一种画法；
3. 选**参考图**（0~6 张，可不传）；想让某一格用某张图的角色，就在那格文字里写「图 1」，程序只对写了「图 N」的格子声明身份基准；
4. **逐格写画面**：点左边宫格小按钮切格，右边写这一格的场景 + 一个可画瞬间 + 景别；**留空的格子会在成图里保持纯白**，不用写「空白」两个字；
5. 选**档位**（默认 / 快速 / 精细），「看完整提示词」可先看整条组装稿。

- 3. 里 0 张参考图时，`no_ref_lock` 段会强制所有非空格的格子用同一个主角（五官、发型、服装、标志物跨格一致）；
- 四/九宫格走 `故事板-参考生图`，六宫格走 `故事板-参考生图-宽幅6格`（8:3 只能直接写死宽高，ResolutionSelector 没有这个预设）；
- 0 张参考图时 `470 LoadImage` 必须有一张图才能通过 ComfyUI 校验，服务会自动上传一张纯白 16:9 占位图填这个空位（提示词里不引用它），所以「0 图也能出」不是靠文生图工作流；
- 提示词库是数据文件 `prompts/board_story.json`（版式硬约束段、空白格句、主体一致性段、参考图规则、彩色/线稿收尾、W1~W4），由 `app/boardlib.py` 唯一负责拼装；创作台预览、实际提交、管理台档位表读的是同一份；
- 管理台 →「档位表 → 宫格分镜故事板」按「画法 × 版式」两段切组合（6 个），档位与参数生效核对跟设定图同构，「去创作台试这个组合」会把版式和画法带回创作台。
